# Roadmap

Breaker Pro focuses on staying lightweight, native, and predictable.

## Near Term

- Improve packaging for Debian-based distributions.
- Document AppImage build steps.
- Add more screenshots for common workflows.
- Expand configuration documentation.

## Later

- Add optional sound notifications.
- Improve accessibility labels across the GTK interface.
- Add translations once the interface stabilizes.
- Publish release artifacts from CI.

## Non-Goals

- Cloud sync or account-based features.
- Heavy background services.
- Cross-platform UI rewrites that increase runtime cost.
